# Учебный frontend-проект

## Описание

Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка».

Тема проекта: многостраничный сайт интернет-магазина или каталога услуг.

## Структура проекта

- `index.html` — главная страница;
- `css/style.css` — файл стилей;
- `images/` — папка для изображений;
- `.gitignore` — список файлов, исключённых из Git;
- `README.md` — описание проекта.

## Что реализовано на стартовой странице

- шапка сайта: синяя плашка с «Прайс-листом» по центру и логотипом слева;
  при наведении плашка уезжает вверх, открывая белое поле, заголовок
  поднимается к верху, а ниже появляется горизонтальный список направлений
  (ссылки пока ведут на `#`); логотип в открытом состоянии инвертируется;
- баннер-представление лучших работ: три изображения сменяют друг друга
  по таймеру, показ останавливается при наведении, переключается точками
  и возвращается в автоматический режим кнопкой «Авто»;
- раздел «О студии» с перечнем направлений;
- подвал с контактной строкой.

Слайдер и меню выполнены только на HTML и CSS, без JavaScript:
переключение слайдов построено на скрытых радиокнопках и селекторе `:checked`,
смена кадров — на `@keyframes` и `animation-delay`, а раскрытие белого поля
шапки — на `:hover`/`:focus-within` и анимированном `grid-template-rows`.
