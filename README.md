# Учебный frontend-проект «Творчество»

## Описание

Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка».
Тема: многостраничный сайт каталога услуг и работ творческой студии.

## Страницы

- `index.html` — главная: первый экран, преимущества, популярные работы,
  направления, «Об авторе»;
- `catalog.html` — каталог: сначала выбор каталогов, затем товары с фильтрами;
- `product.html` — карточка товара, таблица характеристик и модальное окно;
- `original.html` — оригинальные работы с ценами;
- `order.html` — форма заявки и пример оформления идеи;
- `contacts.html` — контакты, соцсети, техподдержка и форма обратной связи;
- `art.html` — арт-искусство: три колонки «Традишн», «Диджитал», «Фон» с ценами;
- `merch.html` — мерч: блоки «Брелоки», «Стикеры», «Типография», «Аксессуары»;
- `craft.html` — крафт: контакты, фильтры и коллаж работ;
- `animation.html` — анимации: коллаж работ;
- `design.html` — дизайн: три раскрывающиеся плашки с портфолио;
- `photo.html` — фотографии: каталог с фильтрами.

## Структура проекта

- `index.html`, `catalog.html`, `product.html`, `order.html`, `contacts.html`;
- `art.html`, `merch.html`, `craft.html`, `animation.html`, `design.html`, `photo.html`;
- `css/style.css` — общий файл стилей;
- `images/` — изображения по направлениям и заглушки;
- `README.md` — описание проекта;
- `.gitignore` — исключения Git.

## Что реализовано

- семантическая разметка: `header`, `nav`, `main`, `section`, `article`,
  `aside`, `footer`;
- единая шапка: крупная плашка «Прайс-лист», которая уезжает вверх при
  наведении и открывает навигацию; логотип слева статичен; цвета
  `#FFF8E7`, `#930500`, `#95BBEA`; ссылки на страницы разделены точками;
- главная: первый экран, преимущества, сетка популярных работ, направления
  с чередующейся раскладкой картинка/текст, блок «Об авторе», ссылка на
  оригинальные работы по центру внизу;
- каталог: два шага — сначала выбор каталогов галочками и кнопка
  «Подтвердить», затем товары с фильтрами; первый фильтр — по каталогам,
  дальше общие фильтры (цена, размер, цвет) и уникальные фильтры направлений;
  фильтры работают на CSS и не меняют URL;
- карточка товара: изображение, описание, таблица характеристик, цена,
  кнопки заявки и CSS-модальное окно быстрого заказа через `:target`;
- страница оригинальных работ: живопись, графика и постеры в единственном
  экземпляре, цены и кнопки заказа;
- формы заявки и обратной связи с HTML-валидацией (`required`, `type`,
  `pattern`); состояния `:focus-visible`, `:invalid`, `:disabled`;
  на странице заявки — пример оформления идеи;
- контакты: телефон, почта, адрес, карточки всех соцсетей и блок
  «Тех. поддержка»; ссылки в навигации ведут на якоря `#social` и `#support`;
- страницы направлений: колонки арта, Pinterest-блоки мерча, коллаж крафта
  с CSS-фильтрами, коллаж анимаций, раскрывающиеся плашки дизайна (`<details>`)
  и CSS-фильтр фотографий;
- позиционирование: `sticky`-шапка, `fixed`-кнопка «Наверх», `absolute`-бейджи,
  `relative`-карточки, `z-index` у шапки и модального окна;
- CSS-переменные, Flexbox и Grid, БЭМ-именование классов.

JavaScript в проекте не используется. Фильтры каталога, крафта и фотографий
построены на CSS (`:has`, `:checked`) и не добавляют переходов и записей
в историю браузера.

## Изображения

Работы лежат в папках `images/Art`, `images/Merch`, `images/Craft`,
`images/Animation`, `images/Design`, `images/Foto`. Для недостающих
примеров сгенерированы белые изображения-заглушки в `images/placeholder` —
их можно заменить на реальные работы, сохранив имена файлов.
