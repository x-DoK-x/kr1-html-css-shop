# Учебный frontend-проект

## Описание

Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка».

Тема проекта: многостраничный сайт интернет-магазина или каталога услуг.

## Структура проекта

- `index.html` — главная страница;
- `css/style.css` — файл стилей;
- `js/main.js` — небольшой скрипт витрины работ;
- `images/` — папка для изображений;
- `.gitignore` — список файлов, исключённых из Git;
- `README.md` — описание проекта.

## Что реализовано на стартовой странице

- шапка сайта: синяя плашка с «Прайс-листом» по центру и логотипом слева;
  при наведении плашка уезжает вверх, открывая белое поле, заголовок
  поднимается к верху, а ниже появляется горизонтальный список направлений
  (ссылки пока ведут на `#`); логотип в открытом состоянии инвертируется;
- витрина лучших работ: крупная работа по центру с подписью под ней,
  по краям — уменьшенные затемнённые превью; раз в 5 секунд работы
  сменяются сами, а по щелчку на превью выбранная работа выходит вперёд;
  у каждой работы пустая ссылка `#`, наведение на витрину ставит показ
  на паузу;
- под витриной — заголовок «Лучшие примеры работ»;
- блок «Направления»: шесть коротких блоков с картинками и описаниями;
  первые два — картинка слева, текст справа, остальные — наоборот;
  без анимаций;
- блок «Об авторе»;
- подвал с контактной строкой.

Меню и раскладка выполнены на HTML и CSS (раскрытие белого поля шапки —
`:hover`/`:focus-within` и анимированный `grid-template-rows`). Автопрокрутка
и переключение витрины — небольшой скрипт `js/main.js` без библиотек.
